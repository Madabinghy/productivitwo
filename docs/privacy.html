Politique de confidentialité — Productivitwo

Dernière mise à jour : mai 2026

1. Qui sommes-nous ?

Productivitwo est une application mobile de productivité personnelle développée et maintenue par Emeric Edmond.

2. Données collectées

Productivitwo collecte uniquement les données que vous saisissez dans l'application :

  • Activités, routines et habitudes que vous créez
  • Sessions de travail et durées enregistrées
  • Objectifs, actions planifiées et progressions
  • Paramètres de l'application

Aucune donnée personnelle (nom, email, téléphone) n'est collectée sauf si vous créez un compte avec votre email.

3. Comment vos données sont-elles utilisées ?

Vos données sont utilisées exclusivement pour :

  • Afficher votre suivi de productivité dans l'application
  • Synchroniser vos données entre vos appareils
  • Sauvegarder vos données en cas de réinstallation

Vos données ne sont jamais vendues, partagées ou utilisées à des fins publicitaires.

4. Où sont stockées vos données ?

Les données sont stockées de deux façons :

  • Localement sur votre appareil
  • Dans Firebase Firestore (Google), un service cloud sécurisé

La synchronisation cloud utilise un identifiant anonyme unique associé à votre appareil. Vos données dans Firestore sont accessibles uniquement par vous.

5. Services tiers

Productivitwo utilise Firebase (Google) pour l'authentification anonyme et le stockage cloud. Firebase est soumis à la politique de confidentialité de Google.

6. Conservation et suppression des données

Vos données sont conservées tant que votre compte existe. Vous pouvez supprimer votre compte et toutes les données associées à tout moment depuis les paramètres de l'application (⋮ → Supprimer mon compte).

7. Vos droits (RGPD)

Vous disposez des droits d'accès, de rectification, de suppression et de portabilité de vos données. Pour exercer ces droits : emeric.edmond@gmail.com
